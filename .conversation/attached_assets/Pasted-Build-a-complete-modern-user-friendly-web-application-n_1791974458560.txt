Build a complete, modern, user-friendly web application named
"NALAM AI – Healthcare Referral Coordination Platform".

PROJECT PURPOSE:
NALAM AI helps community health workers coordinate patient
referrals to Primary Health Centres (PHCs) and hospitals,
track referral progress, and manage patient follow-ups,
especially in rural areas.

DESIGN:
- Create a professional healthcare dashboard.
- Use a clean white background with green and blue accents.
- Make the interface modern, attractive, and easy to understand.
- Use smooth animations, rounded cards, and clear icons.
- Make the website responsive for mobile, tablet, and desktop.
- Use simple English with Tamil and English language options.

1. LOGIN AND DASHBOARD
- Create a login page for healthcare workers, hospital staff,
  and administrators.
- Provide role-based access for different users.
- After login, show a dashboard with total referrals,
  pending referrals, in-progress referrals, and completed referrals.
- Add sidebar navigation with Dashboard, Patients, Referrals,
  Follow-ups, Reports, and Settings.

2. PATIENT REFERRAL CREATION
- Create a form to add a new patient referral.
- Include patient ID, patient name, age, contact number,
  destination PHC/hospital, referral date, and referral reason.
- Add a Create Referral button.
- Validate required fields before submission.
- Save submitted referrals so they appear in the referral list.
- Use demo patient data for initial testing.

3. REFERRAL TRACKING
- Display referrals in a searchable table.
- Show patient ID, patient name, destination facility,
  referral date, and current status.
- Provide status options: Pending, In Progress, and Completed.
- Allow authorized hospital staff to update referral status.
- Add search and filters for date, facility, and status.

4. FACILITY MANAGEMENT
- Display available PHCs and hospitals.
- Allow administrators to manage facility information.
- Let users find referrals assigned to their facility.
- Prevent unauthorized users from accessing restricted records.

5. FOLLOW-UP MANAGEMENT
- Allow staff to schedule a patient's next visit.
- Include patient ID, follow-up date, and notes.
- Display upcoming, overdue, and completed follow-ups.
- Highlight overdue follow-ups on the dashboard.
- Add notification support for future SMS or email integration.

6. REPORTS AND ANALYTICS
- Display total referrals and their current statuses.
- Show facility-wise referral statistics.
- Include charts for pending and completed referrals.
- Ensure all statistics are calculated from actual saved records.

7. AI ASSISTANT
- Add a multilingual AI assistant that supports Tamil and English.
- Help users understand how to use the platform.
- Explain referral procedures and provide general healthcare
  information from verified sources.
- Do not diagnose diseases or prescribe medicines.
- Do not allow AI to make medical decisions.
- Clearly distinguish implemented AI features from demo features.

8. SECURITY
- Implement secure authentication and role-based permissions.
- Protect sensitive patient information.
- Validate all inputs and restrict access to authorized users.
- Do not expose passwords, API keys, or private patient data.
- Use fictional patient records for demonstrations.

9. TECHNICAL REQUIREMENTS
- Build a fully functional website, not just a static design.
- Connect the frontend to a suitable database and backend.
- Save patient referrals, status updates, and follow-up records.
- Ensure data remains available after refreshing the page.
- Implement proper form validation and error messages.
- Include loading indicators and success notifications.
- Do not use fake buttons or non-functional navigation.
- If external services or API keys are required, explain how
  to configure them securely.
- If any feature cannot be fully implemented, clearly state why.

FINAL RESULT:
Create a polished, functional NALAM AI healthcare platform
that is easy for rural healthcare workers to use.
Prioritize simplicity, accessibility, patient privacy,
and reliable referral tracking.

Build the application step by step and ensure that every
implemented feature works correctly.
